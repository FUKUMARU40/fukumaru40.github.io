Chatbot Sample · Education

英会話教室のFAQチャットボット

解決した課題

  • 料金・コース・体験などの定型問い合わせが多い
  • FAQが見つけづらく、訪問者が途中で離脱してしまう
  • 営業時間外に質問対応ができない

主な機能

  • 料金・コース案内の自動応答：よくある質問（料金体系／コース違い）を即時回答
  • 体験レッスンの案内・導線設計：申し込みに必要な情報や流れを分かりやすく提示
  • アクセス・営業時間などの基本情報対応：迷いやすい情報をチャットで最短提示
  • 質問を迷わせない会話設計：1問ずつ進行／選択肢提示／例外時の案内

設計のポイント

  • 24時間対応で機会損失をゼロに：営業時間外でも体験レッスン案内・基本情報を自動提供
  • 体験申込みへの自然な誘導：質問の流れの中で、申込みリンクへスムーズに案内
  • FAQ整理から実装まで一気通貫：重複・バラつきを整理してから設計し、迷わない導線を実現

入会・コース別データの集計ダッシュボード

解決した課題

  • Excelデータが蓄積されているが、グラフ化・集計に毎回時間がかかる
  • 月次レポートを手作業で作成しており、ミスや工数が発生している
  • データを見やすい形で共有・確認できる仕組みがない

主な機能

  • Excelデータをそのまま活用：既存データを大きく加工せず移行・活用可能
  • 現場が使い続けられる設計：更新作業を自動化し、担当者の工数をゼロに

Operation Design · 8 Years

業務設計・マニュアル化・FAQ整備

概要

教育業界（英会話）での管理部8年の経験を通じて、現場の業務を「誰でも回る仕組み」に落とし込む設計を担当してきました。

主な経験

  • FAQ・マニュアルの整備：問い合わせが多い業務を洗い出し、FAQ化・マニュアル化
  • 業務フローの設計・改善：現場スタッフが迷わず動ける手順書・フローの作成
  • 新人教育・オンボーディング設計：入社後に即戦力になれる導線の整備
  • 問い合わせ対応の効率化：定型質問を仕組みで解決し、担当者の工数を削減

この経験がAI活用に活きる理由

「何をFAQ化すべきか」「どう会話設計するか」は、業務を深く知らないと正確に設計できません。 飲食業界9年・英会話業界現場5年＋管理部8年の経験があるため、 現場で本当に使われるかと組織として運用できるかの両方の視点から設計できます。

AI Tool Adoption

Claude Codeを活用した業務効率化

概要

AnthropicのAI開発支援ツールClaude Codeを活用し、チャットボット構築・ドキュメント整備・プロンプト設計などの業務を大幅に効率化しています。

主な活用シーン

  • ① プロンプト設計・最適化：システムプロンプトの複数パターンを素早く生成・比較。チャットボットの精度向上に直結。
  • ② FAQ原稿の整理・リライト：大量のFAQテキストの重複削除・表現統一・カテゴリ整理を短時間で処理。
  • ③ ドキュメント・マニュアル作成：業務フロー・運用ルール・提案資料などの構造化文書を高速生成。
  • ④ Difyのナレッジベース整備：取り込む原稿の形式整理・表現最適化をClaude Codeで効率化。

効果・ポイント

  • 従来数時間かかっていたドキュメント整備・プロンプト作成が大幅に短縮
  • 「言いたいことは分かるが文章にできない」業務課題をAIで言語化・整理
  • GPT系・Gemini・Claudeを用途別に使い分け、最適な品質を実現
Side Project · Automation

X（Twitter）自動投稿ボットの構築

概要

副業・受託案件（チャットボット／LP／BI）の集客を目的に、X（Twitter）への自動投稿システムを構築・運用中。 Claude APIで投稿文を自動生成し、GitHub Actionsで1日3回スケジュール投稿する仕組みを実装しました。

使用技術

Python (tweepy) Claude API GitHub Actions Cursor Claude Code

主な機能

  • Claude APIが業種・強み・実績をもとに毎回異なる投稿文を生成
  • work_episodes.md に実体験を追記するだけで投稿の質が向上する設計
  • GitHub Secrets でAPIキーを安全に管理（.env をGitに含めない構成）
  • --check オプションで認証確認のみ実行できるテストモード対応

ポイント

  • 「書く」作業をゼロに：毎日の投稿文作成をAIが代替し、集客活動を自動化
  • Cursorで2時間以内に構築：AIコーディング支援ツールで高速に実装
  • 運用コストほぼゼロ：GitHub Actions の無料枠で継続稼働
